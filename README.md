<h2 id="highlights">✨ Highlights</h2>

- Put your socials, projects, and a bit about you on one public page.
- Pick a layout, then tune the colors, type, backgrounds, cards, and motion.
- Add up to three tracks, a media gallery, and your own profile imagery.
- Set the scene with a custom visitor intro and optional visual effects.
- See edits live in the preview. Your profile changes save automatically.
- Send people straight to your page with your own username link.

<h2 id="quick-start">🚀 Quick start</h2>

You’ll need Node.js 20.19+ and a Supabase project.

1. Install dependencies:

   ```bash
   npm install
   ```

2. Copy `.env.example` to `.env.local` and add your Supabase project URL and anon key.
3. Apply the SQL migrations in `supabase/migrations` to your Supabase project, in numeric order.
4. Start the app:

   ```bash
   npm run dev
   ```

Open `http://localhost:3000` to get started.
